INTERNMATE AI — FULL INTEGRATION PROTOTYPE

1. Extract the ZIP.
2. Backend terminal:
   cd backend
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   Copy-Item .env.example .env
   notepad .env
   # Set GEMINI_API_KEY to a NEW private key; save and close.
   python -m uvicorn main:app --reload
3. Frontend terminal (from project root):
   cd frontend
   npm install
   npm run dev
4. Open http://localhost:5173
